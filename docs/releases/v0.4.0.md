First release of the MHFE implementation for suite `MHFE-BIP39-256-EXPERIMENTAL-3`, as defined by
[specification v0.4.0](https://github.com/hobby-eng/mhfe-spec/releases/tag/v0.4.0).

## Format

Suite 3 replaces suite 2: twelve Feistel rounds, each with Argon2id over 2 GiB and four lanes,
twelve passes by default, PIM 0–1023 and memory levels 0–21 (2 GiB to 3 TiB). Passwords are
normalized with NFKD under Unicode 17.0.0. Containers of suite 2 are not readable by this version;
recover them with release v0.3.0.

## Command-line tool

- `encrypt`, `decrypt`, `check`, `password` and `serve`, and a menu with the arrow keys when `mhfe`
  starts without arguments.
- Every new container is decrypted once more and marked verified only when it turns back into the
  original phrase.
- `check` rehearses a recovery against a receiving address, the master key fingerprint or the
  built-in check of a 12- to 21-word original, without ever showing the phrase.
- Secrets are typed at hidden prompts. The source phrase, the typed password and the recovered
  phrase are shown on the terminal's alternate screen, so that they do not stay in the scrollback.
- A free-memory check runs before Argon2 starts and respects the process's cgroup limit on Linux.

## Browser package

A promise-based client that runs every operation in a disposable Worker, the Rust core as
WebAssembly, and the reference Argon2 C code built with Emscripten, threaded for cross-origin
isolated pages and single-threaded otherwise. `mhfe serve` and the `mhfe-launch` scripts open a
page in fast mode.

## Downloads

- The command-line tool for Linux x86-64 and ARM64, Windows x86-64, and macOS ARM64 and x86-64. The
  x86-64 builds come as a baseline build and an SSSE3 build, which is 7 to 10% faster.
- The browser package.
- Every archive except the macOS ones is built reproducibly in a pinned container; the macOS ones are
  built on GitHub's runners. `SHA256SUMS` lists the hashes, every archive carries a build-provenance
  attestation, and `BUILD-INFO.txt` names the source commit.
