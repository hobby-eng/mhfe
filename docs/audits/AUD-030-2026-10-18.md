### Findings

#### AUD-030-BLD001 — Medium — Repacking an existing ZIP retains obsolete entries

- **Affected:** `packaging/pack-archives.sh::pack_zip` and its release/verification callers.
- **Reproduction:** Pack two synthetic files, remove one, change/add current content and pack to the same ZIP path. Baseline differs from a fresh archive; a controlled failed writer also overwrites the previous destination.
- **Expected / observed:** Only current staging content should be present, with the previous archive preserved on failure. ZIP add/update instead retained absent old members.
- **Impact:** Incorrect local repeat packaging, not a demonstrated corrupted published release. **Release blocking:** false; fresh canonical destinations avoid this trigger.
- **Fix / verification:** Build a fresh sibling temporary ZIP, propagate failures even in conditional callers, then rename on success. Literal member/content controls, fresh-byte comparison, failure preservation and existing umask controls pass; independent narrow review accepted the exact implementation.

#### AUD-030-API001 — Low — Non-object browser options silently select defaults

- **Affected:** `web/runtime-parts/arguments.js::requireKnownKeys` and optional-options methods.
- **Reproduction:** `make(42)`, `drawPhrase(false)` and other non-object shapes reach a worker/default operation instead of the required `TypeError`.
- **Expected / observed:** Omitted/undefined options remain defaults; supplied primitives, arrays, functions and null must not silently select them.
- **Impact:** Unexpected generation/check work from malformed caller configuration; no secret compromise established. **Release blocking:** false.
- **Fix / verification:** Shared synchronous container validation before destructuring. Nine optional-options families reject eight invalid shapes without a worker; omitted/undefined/empty-record controls still reach the external seam. Node and real-browser regressions pass; independent review accepted the source.

#### AUD-028-API005 — Low — Follow-up: browser wishes are collected before count refusal

- **Affected:** `web/wallet.js::wishesOf`, public `describeDraw`/`drawPhrase`.
- **Reproduction:** An oversized array with a throwing first-entry getter is traversed before the Rust-owned one-word limit is checked.
- **Expected / observed:** Refuse count before entry access, framing, encoding, startup or drawing. Baseline collects whole invalid lists first.
- **Impact:** Caller-controlled local work/copies before refusal, not a measured OOM or remote attack. **Release blocking:** false.
- **Fix / verification:** Synchronous count/type admission and fixed-index bounded traversal; existing framing/positions/cancellation remain. Two deliberate scalar/message copies have explicit reasons, comparisons to Rust metadata/messages and damaged controls. Maximum-plus-one/4,096-entry, malformed Proxy length and overridden-collection controls pass. The review's sentence-compatibility correction is independently accepted and verified against literal public messages.
- **History:** This closes the demonstrated page-side variant, not a new ID or a claim that prior native/raw fixes were absent.

#### AUD-030-DOC001 — Low — Erasure guidance retains the former phrase-text refusal code

- **Affected:** `docs/BROWSER-PACKAGE.md` and `web/client.d.ts::readPhrase`.
- **Reproduction / expected:** The guide's raw phrase admission says `INVALID_REQUEST`, but its erasure section/declaration still says `INVALID_PASSWORD_TEXT`. Document raw admission separately from direct secret encoding.
- **Impact:** Incorrect host error guidance; no new runtime leak. **Release blocking:** false.
- **Fix / verification:** Guides and declaration now match current caller paths. Exact-byte independent review and current source/package checks accepted the correction.

#### AUD-030-DOC002 — Low — Retry guidance omits retained failed self-check components

- **Impact:** Incorrect host recovery guidance, not an implementation bypass. **Release blocking:** false.
