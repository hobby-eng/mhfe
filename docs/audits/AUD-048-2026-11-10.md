## Review evidence

### Scope and methodology

Every change after v0.7.0 (8a15bed), all in the uncommitted working tree of 0.8.0: seed-phrase generation removed (mhfe new, chosen words, the draw of the wallet check, the browser package's drawPhrase and describeDraw, the wallet module's random source and two error codes), an own Unix handler of Ctrl+C, SIGTERM and SIGHUP instead of ctrlc, reproducible macOS archives linked by Zig in the canonical build with cargo xtask macos-binary, the release workflow's macOS job, and the documents. All 32 CHECK items were assigned; code that did not change was not reviewed again.

Reviewer A read the library, the command line, the signal handling and xtask; reviewer B read the documents, the build and release files and the browser package. The coordinator ran every check once, one at a time, and checked each finding against the code before accepting it. Public test data only.

#### AUD-048-BLD001 — Low — cargo xtask macos-binary panics on, or mishandles, code directories outside its assumptions

- **Category:** BLD.
- **Severity:** low.
- **Status:** fixed.
- **Release blocking:** false.
- **Affected files and builds:** xtask/src/macho.rs:93, xtask/src/macho.rs:123, xtask/src/macho.rs:140-149.
- **Rules:** RUST-05, CORE-48.
- **Reproduction:** By reading rehash_pages: a page-size byte of 64 or more overflows the shift; a code limit beyond the file or more code slots than pages make the slice panic; slot * page can overflow; a page-size byte of 0 hashes 1-byte pages; nothing checks that the code directory lies inside the signature, that the code limit ends before the signature, or that LC_UUID's size covers 16 bytes.
- **Expected behavior:** Every field out of range or unsupported is refused with the tool's error.
- **Observed behavior:** Panics, or a silently wrong signature for a page-size byte of 0; no test covers a program without a signature.
- **Impact:** Bounded: the input is the project's own Zig output inside the reproducible build, and the result runs on a Mac in the release workflow.
- **Evidence:** Reviewer A, by reading against the CodeDirectory layout; confirmed by the coordinator.
- **Recommended fix:** Refuse each case and use checked arithmetic and get() for page slices; add tests for a program without a signature and for each refusal.
- **Required verification:** cargo test -p xtask; two canonical builds give the same macOS archives.
