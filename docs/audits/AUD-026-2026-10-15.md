## Review evidence

### Scope and methodology

The coordinator read current workspace/repository instructions and all eight guide files, the wallet-full-audit entry and four canonical procedure documents. Source/native and browser/tooling reviewers received distinct scopes, public-only data and no build/mutation authority. The second reviewer separately reconciled completeness and independently challenged the native candidates; the coordinator challenged both reviewers. The same reviewer later reviewing completeness is independent of the coordinator/native scope, but is not an independent second review of every own browser file.

The 2 GiB combined local-check budget preserves an OS/other-session reserve. Heavy executions ran sequentially with CARGO_BUILD_JOBS=1, RUST_TEST_THREADS=1 and EMCC_CORES=1. The largest later conservative sampled descendant sum was 1,386,800 KiB in Firefox fast mode. Earlier process-group-only accounting is labeled in command metadata; shared pages may be counted more than once. No specified production cost was reduced.

Every current source/input/document file received an explicit functional, data or document method: 155 native/build, 187 browser/tooling, 68 tests/vendor/assets, 22 known-answer/generated-data files and 22 coordinator documents; cross-scope reads/reuse count once. The 22 known-answer/table files include 9,768 lines; an audit parser read all 27 positive published transcripts / 324 round cells and 502 Unicode width intervals. Those structural comparisons are not new Argon2 derivations or Unicode regeneration. The parser compares fixture-backed protocol fields and recovery order; startup flags are parsed/count-checked (10), without an independent expected per-vector startup set. Startup-selection source review is separate.

Of 757 historical audit files, 3 active/legacy caller-chain helpers received functional review; the remainder received classification/hash, schema/pair/link/procedure/binding and Python AST checks where applicable. This does not claim a new semantic audit of every 13.7 MiB historical report/generator. All 25 current record pairs pass the recorded live gate. Stronger isolated negative controls nevertheless demonstrate BLD004/005; independent enumeration of the actual baseline records found no orphan or JSON-date mismatch.
