#### AUD-031-API001 — Low — Word-hint requests have no raw utility byte admission

- **Category:** API.
- **Severity:** low.
- **Status:** open.
- **Release blocking:** false; The demonstrated local boundary, interactive or comment scope does not establish secret compromise or a failed mandatory release artifact.
- **Affected files and builds:** ['src/wasm_api/word_hints.rs:36-45', 'src/word_hints.rs:195-205', 'web/runtime-parts/modules.js::wordHintsOf'].
- **Reproduction:** node --max-old-space-size=128 docs/audits/AUD-031-harnesses/word-hints.mjs
- **Expected behavior:** An outside utility request has an explicit size bound; reuse the existing InputText domain, preserving normal last-word behavior. This is a coding-rule bound, not an altered cryptographic-format requirement.

- **Evidence:** Local-only word-hint-boundary.command.json.
- **Recommended fix:** Settle the public hint input contract and use library-owned admission in the raw binding and pre-encode class paths; expose/reuse needed metadata. - **Required verification:** Exact max/max+1 byte controls with multibyte input; normal hints/completions; stable error code; pre-copy/worker ordering; document any source API signature/limit changes.
- **History:** Existing ID preserved; AUD-031 evidence remains historical. AUD-032 reassesses the same current source and newly executes the listed controls.
