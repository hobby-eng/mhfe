# The vendored C files of the Argon2 engine that build.rs and scripts/build-argon2-wasm.sh both
# compile, the one list of them: one file per line as "<part> <path>", the path from the repository
# root. packaging/Dockerfile.reproducible copies this file for the browser build. The parts:
#
#   common    every build
#   portable  the portable core: native builds off x86-64, and the browser build, where the SIMD
#             core opt.c gave no speed-up and would exclude browsers without WebAssembly SIMD
#
# The browser build takes the files in the order of these lines, the native builds those of each
# part; another order would change the bytes of a build. On x86-64, build.rs compiles opt.c and
# src/engine/argon2_simd.c in place of the portable core.
common vendor/phc-winner-argon2/src/argon2.c
common vendor/phc-winner-argon2/src/core.c
common vendor/phc-winner-argon2/src/encoding.c
common vendor/phc-winner-argon2/src/thread.c
portable vendor/phc-winner-argon2/src/ref.c
common vendor/phc-winner-argon2/src/blake2/blake2b.c
